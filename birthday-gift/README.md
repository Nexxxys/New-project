# Birthday gift

Это отдельный статичный сайт-подарок. Основной тренажер в родительской папке не менялся.

## Как поставить фотографии

1. Открой папку `photos`.
2. Замени файлы `фотка 1.jpg` ... `фотка 10.jpg` на свои изображения, сохранив их названия.
3. Номера файлов соответствуют слайдам по порядку.

Кадры на сайте квадратные, до 302 px по ширине, что примерно соответствует 8 x 8 см в CSS-единицах.

## GitHub Pages

1. Создай на GitHub новый репозиторий и добавь в него содержимое папки `birthday-gift`.
2. В репозитории открой `Settings` -> `Pages`.
3. Выбери `Deploy from a branch`, ветку `main` и папку `/(root)`.
4. GitHub покажет публичную ссылку на сайт через несколько минут.
